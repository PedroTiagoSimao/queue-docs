The Google app is built around a set of core features that work together to help you stay organized, productive, and in sync. Here's a breakdown of what the app offers and how each feature helps you.

## Task and item management

Create, assign, and track work items in one place. Every item can have:

- A **title** and **description**
- An **assignee** (a workspace member responsible for it)
- A **due date**
- **Labels** or **tags** for categorization
- A **status** (e.g., To Do, In Progress, Done)

You can view items as a list, board (Kanban-style), or calendar.

## Real-time collaboration

Multiple workspace members can work on the same project simultaneously. Changes appear in real time — no need to refresh. You can:

- Comment on any item
- Mention teammates using `@name`
- Attach files and links
- View activity history for any item

## Notifications and activity feed

Never miss an update. The app sends notifications when:

- You're mentioned in a comment
- An item assigned to you changes status
- A deadline is approaching
- A teammate completes a shared task

You can configure exactly which events trigger notifications in [Notification Settings](/guides/notifications).

## Search and filters

Find anything quickly with full-text search across all your projects and items. Use filters to narrow results by:

- Assignee
- Status
- Due date range
- Labels or tags
- Project

## Integrations

Connect the tools you already use. The app integrates with a wide range of popular services — see the [Integrations overview](/integrations/overview) for the full list.

## Customization

Make the app your own:

- Choose a light or dark theme
- Rearrange the sidebar
- Set default views per project
- Configure keyboard shortcuts
