The Google app is designed to keep everything within reach. This guide walks you through the main areas of the interface so you can find features quickly and move around confidently.

## The main areas

When you log in, the screen is divided into three main zones:

| Zone | What's here |
|---|---|
| **Sidebar (left)** | Navigation, projects, settings |
| **Main panel (center)** | Your current view — list, board, calendar, or dashboard |
| **Top bar** | Search, notifications, account menu |

## The sidebar

The sidebar is your primary navigation tool. From here you can:

- Switch between **projects** by clicking their names
- Access **Settings** at the bottom of the sidebar
- Collapse or pin the sidebar using the arrow icon at the top
- Create a new project with the **+ New Project** button

<Tip>Right-click any project in the sidebar to rename it, change its color, or archive it.</Tip>

## The top bar

The top bar gives you quick access to global functions:

- **Search** (`/` or `Cmd+K` / `Ctrl+K`) — Find anything in your workspace instantly
- **Notifications** (bell icon) — View recent activity and alerts
- **Account menu** (avatar, top right) — Access your profile, settings, and sign-out option

## The main panel

The main panel shows your current context — a project's items, a dashboard, or a settings page. You can switch how items are displayed using the **view toggle** at the top right:

- **List** — A compact, scrollable view of all items
- **Board** — A Kanban-style column layout grouped by status
- **Calendar** — Items laid out by due date

## Keyboard shortcuts

Use shortcuts to navigate faster:

| Shortcut | Action |
|---|---|
| `Cmd+K` / `Ctrl+K` | Open search |
| `?` | Show all keyboard shortcuts |
| `N` | Create a new item |
| `G then H` | Go to home dashboard |
| `G then S` | Go to settings |
| `Esc` | Close modal or panel |

## Finding features

If you're unsure where a setting or feature lives, use the **search bar** — it finds both content (items, projects) and features (settings pages, actions). You can also open the **command palette** with `Cmd+K` / `Ctrl+K` to run any action directly from the keyboard.
